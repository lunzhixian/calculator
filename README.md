# 图形化计算器 (Graphical Calculator)

一个简洁、美观的图形化计算器网页应用，支持鼠标点击和键盘输入。

## 功能特性

- 🎨 现代化毛玻璃 UI 设计（Catppuccin 配色）
- ⌨️ 完整键盘支持（数字、运算符、回车、退格、Esc/C 清空）
- ➗ 高精度计算（Decimal 运算，避免浮点误差）
- 🧮 支持运算：加、减、乘、除、幂、平方、开方、百分比
- 🔢 括号与科学计数法显示
- 🖱️ 按钮动画与操作符高亮

## 使用方法

直接用浏览器打开 `calculator.html` 即可，无需安装任何依赖。

## 键盘快捷键

| 按键 | 功能 |
|------|------|
| `0-9` / `.` | 输入数字 / 小数点 |
| `+ - * / ^` | 运算符 |
| `Enter` / `=` | 计算结果 |
| `Backspace` | 退格删除 |
| `Esc` / `C` | 清空 |
| `%` | 百分比 |
